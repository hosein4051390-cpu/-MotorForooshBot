# 🚀 MotorFrooshBot v2

نسخه‌ی جدید ربات `@MotorFrooshBot` با Python و aiogram.

## منوی اصلی

- 🛍 فروشگاه
- 💳 پرداخت
- 🎁 سه دوره رایگان
- 📚 دوره‌های آموزشی
- 🚀 خدمات
- 👤 حساب من
- 🎟 پشتیبانی
- 📞 ارتباط با ما

## نصب

Python 3.10 یا بالاتر پیشنهاد می‌شود.

```bash
pip install -r requirements.txt
```

فایل `.env.example` را به `.env` تغییر نام بده و توکن ربات را داخل آن قرار بده:

```env
BOT_TOKEN=توکن_واقعی_ربات
```

سپس:

```bash
python main.py
```

در تلگرام وارد `@MotorFrooshBot` شو و `/start` بزن.

## امنیت

توکن ربات را داخل کد، گیت‌هاب یا برای دیگران ارسال نکن.
